# Kai River Apparel — design mockup

Homepage and product page concept for Kai River Apparel, built to preview the
layout before anything is set up in Square.

**Everything here is placeholder** — copy, prices, product names and imagery.
Grey/tinted blocks mark where real photography goes.

- `index.html` — homepage
- `product.html` — product detail page
- `styles.css` — shared styles

Open `index.html` in a browser, or view the live preview linked in the project chat.
